# Contributing to Aegis AI

Thank you for your interest in **Aegis AI — Autonomous Smart Home Guardian**.

Aegis is being developed for the **Arduino Physical AI Challenge India 2026**.

## Contributions

For:

* Bug reports
* Feature suggestions
* Hardware improvements
* Software improvements
* Documentation improvements
* Collaboration
* Questions about the project

Please contact:

**[srihari.builds@gmail.com](mailto:srihari.builds@gmail.com)**

When reporting an issue, include as much relevant information as possible, such as the problem, expected behaviour, error messages, and affected hardware or software.

## Important

Please do not send:

* API keys
* Passwords
* Private credentials
* Other sensitive information

Thank you for supporting Aegis AI.
