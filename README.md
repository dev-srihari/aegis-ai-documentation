# Aegis AI

> Autonomous Smart Home Guardian

Aegis AI is an intelligent smart home system built using the Arduino UNO Q for the Arduino Physical AI Challenge India 2026.

The project combines embedded systems, Artificial Intelligence, sensors, and automation to improve home safety, security, and energy efficiency through on-device processing.

## Features

- Motion Detection
- Gas Leak Detection
- AI Decision Engine
- Smart Automation
- Edge AI
- Local Processing
- Energy Optimization

02_Hardware - Components and wiring

03_Software - Arduino and Python code
